# LLM 与程序分工的单任务重构

保留上一版全部文件，在独立子目录重构。仍使用同一个 τ²-bench retail 任务 0、相同共同历史及用户改口消息；不增加任务种类，不训练模型。

- `ledger.py`：从官方工具结果直接入账，按换货规则建立依赖，维护版本/来源/选择性失效，以 Decimal 计算金额，绑定确认指纹和检查提交前提。
- `run.py`：LLM 只解释用户语义、确认适用范围并自主选择下一项工作；框架组读取程序生成的紧凑状态，原始证据可按需调取。
- `checks.py`：离线检查状态变化、保留依据、错误确认、漏项、错配、库存变化和重复写入。
- `设计说明.md`：职责、上下文与对照边界。
- `selfcheck/`、`results/`：独立自检及在线记录，保存快照、语义输出、原始模型调用、实际工具参数和状态前后差异。

```powershell
Set-Location 'D:/experimentn/Codex工作区/实验/03_确认后局部改规格/hybrid_v2'
$env:PYTHONIOENCODING = 'utf-8'
```

在线验证只对同一任务各运行一次。两组使用相同模型、业务政策、官方工具及程序辅助工具、语义适配器和提交检查。直接组读取原始历史；框架组读取有来源的当前状态及最近观察。该对照检验“程序状态及上下文组织”的实现，不与上一版的不设公共门禁实验混报成绩。
