# 第23轮：三个模块闭环验收与同状态轨迹试采

对应分页紧凑版申报书2.1：（1）Agent如何依据动态业务状态合理开展认知决策；（2）如何利用执行反馈评价并提升Agent的认知决策能力。保持“状态约束与建模、认知决策、任务执行与反馈”三个模块，当前API模型核验数据生成，不训练模型。官方Agent受控端到端对照另批安排。

## 修复与共同边界

状态分别显示原购SKU/原购价格及来源、初始请求（历史）、当前有效/最新许可规格及实际原话、当前完整授权及绑定参数与批准原话。金额、库存、同产品、当前引用及授权匹配由程序检查。旧分析随有效规格变化失效但保留审计，旧执行反馈不再携带过去的“待补前提”冒充当前条件；新的前提缺口从当前状态重新计算。

分析程序区分exact_feasible、no_exact_match和evidence_insufficient。空精确集合是有效结果，同时给出可协商替代集；替代集不能自动成为用户许可。LLM用核定事实分析规格取舍与澄清问题，不负责重算金额或把替代许可变为最终批准。拟案只产生当前可行方案；诊断冲突使用analyze，不能用prepare强行形成不可行当前方案。模型原始参数与程序规范化参数分别记录；已知订单#前缀的唯一别名可规范化，不同订单不能；整单操作必须parameters={}，旧SKU或其他显式参数不被悄悄覆盖。

每次真实新用户回复先完成语义解释和来源校验，再把最新状态交决策模型；每轮工作执行后反馈具体结果/拒绝原因。不存在自动替模型选择prepare/confirm/submit的推进。两次相同拒绝后的再次重复保留，三次停止为repeated_same_rejection。程序核验失败、语义解释错误、模型工作选择错误、环境偏离、JSON解析和网络异常分别记录。

## 阶段与预注册数量

联调只用旧93，单独pilot目录，不进入正式重复。离线回归在tests；冻结src、tests、当前任务/提示/评分与runner后跑旧题：93/conflict先analyze两次、93/feasible先clarify两次，29真实旧完整批准后要求变更两次，102完整授权撤回快照两次，共8条。旧题作为修复验收而非组间收益估计；同一版本均正确办理、当前授权与硬约束通过、没有重复旧规格/历史引用故障，且两个93首步执行成功，才开启新题阶段。

新题11和16来自未用于本轮模型调试的不同基础题/订单。原业务为退货，原题原样归档，另保存子任务、公开两商品换货改编及cap动态变体；不能称原题原生benchmark成功。既有21轮仅列为未来候选，没有运行；22轮未采样。新任务只做离线结构校验，不以它们调提示。

新题A：2题×conflict/feasible两状态×direct/candidate两组×两次=16条。程序只改变公开有符号整单差额上限，底层目录库存、对象和其他原话相同。候选组在同样完整当前状态上额外看到按工作/对象/ID字面排序的工作及前提；无隐藏答案或最优排序。首步前暂停自动推进，两组同JSON工作/对象/引用/预期/理由输出。评分允许冲突状态analyze或可行替代clarify；可行状态还允许prepare；原始选择、对象、理由与执行成功分开报告。仅不同工作不判优劣。

新题B：选11/conflict和16/conflict，每个状态first analyze/first clarify×两次，共8条完整续行。完整起点一致；先澄清的报价取按SKU字面顺序第一个可见可协商选项，不是隐藏最优；先分析允许空精确集，其后共同direct续行。用户对实际提出的有货/cap内替代给明确、带supersedes的规格许可；只在实际完整可行方案获询问时给独立批准。用户脚本不细分可行备选的主观喜好，因此分析价值只在本受控范围解释，不推出普遍最优顺序。不同可行规格可同样正确。

## 模型、预算与冻结

固定deepseek-flash，temperature0，thinking disabled，原生RetailTools和retail policy。每请求最大输出1700，超时60秒，SDK重试0，仅网络/超时/408/429/500/502/503/504一次相同请求重试；未知用量保留未知。每轨迹40次Agent请求尝试、180000已知词元软限、24业务操作及35轮保护。失败保留，不替补。记录实际返回model/responseID/用量/cache字段，别名不等于可核验权重修订。模拟用户是程序脚本，单列程序交互，模拟模型调用为0。评测编排会话开销不计入Agent且未量化。

先判完整正确登记、scope/同产品/库存/精确Decimal金额/cap/原支付、当次当前完整批准和实际DB，再核对当前理由与对象。办结不能抹去中间错误。首步适切性主指标，调用/词元/缓存为辅。B双方同质量且无环境/执行契约异常才比较成本；同题两重复方向一致才列作本批偏好候选，持平或反转保留为并列/不稳定。后续结果、隐藏分支和用户未来回复不进Agent输入。试采只生成示范/偏好候选清单，不训练或生成自动可用偏好标签。
