# 同状态候选共同续行：单任务开发验证

对应申报书 3.1.4，优先实现一个局部实验，不宣称已完成全部三组框架评测。

同一个 Task 0，在已确认、未提交时，经真实用户消息撤回键盘无背光许可。RGB、clicky 必须保留，全尺寸优先，较小尺寸尚未授权。恒温器、身份、支付依据保留。完整官方库存仍在可见事实中，没有人为藏起证据。

- `engine.py`：六部分状态、四值条件与依据有效性、分阶段影响复核、候选 W/前提/ready、指令 u、同一执行器及完成检查。
- `exchange_core.py`：上一版确定性换货适配器的原样副本，负责事实缓存、金额、方案指纹与公共写入前检查；旧文件不修改。
- `run.py`：冻结策略、状态/数据库/私有用户状态复制、两个不同首步、共同策略续行、成本分项及独立语义审计。
- `checks.py`：上线前离线验收，测试替代许可不等于交易确认、分支隔离等。
- `protocol.md`：本轮冻结范围、预算、数学对象与评价边界。
- `selfcheck/`、`results/`：场景、快照、候选、原始请求、状态前后、模型回复、官方写入、V 观察和审计。
